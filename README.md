# 🌄 Tanah Toraja Tourism Website

A responsive, feature-rich website project dedicated to exploring the rich culture, tourism destinations, traditional culinary delights, and history of Tanah Toraja. 

---

## 🛠️ Tech Stack & Environment

- **Frontend Structure:** HTML5 (`index.html`, `index2.html`, `Contactus.html`).
- **Styling:** CSS3 & Custom CSS using Media Queries for full responsiveness across desktops, tablets, and mobile devices (`css/style.css`, `css/style2.css`, `css/style3.css`).
- **Interactivity & Animation:** JavaScript (Navbar, dropdown menus, and dynamic animations).
- **Design & Tools:** Figma (UI/UX Wireframes & Layouts), Visual Studio Code.

## ✨ Key Features

- **Home Page:** Welcoming landing page featuring an overview of Tanah Toraja ("Melangkah ke Toraja, Menyapa Warisan Dunia") with responsive navigation.
- **Information Section:** Deep dive into local history (*Sejarah Tanah Toraja*) and philosophy of life (*Filosofi Hidup*).
- **Culture Section:** Detailed categories covering traditional culinary delights (*Pa'piong*, *Ballo/Tuak Toraja*, *Pamarassan*), ceremonies (*Rambu Solo'*, *Rambu Tuka'*, *Ma'nene'*), traditional clothing (*Pakaian Toraja*), and architecture (*Tongkonan*, *Lumbung Padi/Alang*, *Ukiran Kayu*).
- **Gallery & Location:** Visual showcase of Toraja's beauty paired with an interactive map location.
- **Interactive Feedback Form (*Kesan dan Pesan*):** User form supporting inputs for names, contacts, dates, gender selection, and review submissions.
